## English — v0.3.0

embo 0.3.0 — parallel worktrees.

Run several features at once in separate git worktrees and they share
one index and memory. No worktree needs re-indexing, and deleting one
loses nothing — the state lives in the main tree.

/embo:worktree — opens, lists, and cleans up worktrees. It refuses to
delete one that still holds uncommitted work.

embo now warns when you are editing one task's files on another task's
branch, and names a branch that matches.

/embo:wrapup asks less about obvious things: it records the session's
work itself instead of asking you to approve each item.

/embo:init also indexes the code inside git submodules — repos using
them were previously indexed without it.

/plugin marketplace update embo then /reload-plugins
