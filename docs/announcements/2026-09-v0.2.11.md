## English — v0.2.11 (matches the Ukrainian voice)

embo 0.2.11 — a small one.

If you customize your Claude Code status line, embo no longer
overwrites it on session start. It looks for an embo:auto-refresh line
in ~/.claude/statusline.sh; if that line is gone, your version stays
untouched — keep it, and automatic updates keep coming (they're worth
it).

/plugin marketplace update embo then /reload-plugins

## English — three-release narrative (0.2.9 → 0.2.11)

For announcing the cycle as one story (rule S7: related point releases
announced together). NOTE: the original 0.2.9+0.2.10 English post was
never saved; this is a faithful reconstruction from the CHANGELOG and
memory, not the exact wording first posted.

embo 0.2.9 – 0.2.11

A few releases about keeping your work intact — the session's, the
agents', and now your own setup.

/embo:wrapup closes a session by checking that your docs tree reflects
what actually happened — decisions, findings, and progress that never
made it into a file get flagged before you stop. Init also got faster
on large task trees.

Spawned subagents now inherit the session's working rules: they decide
routine things themselves, check the docs before stating facts, and
hand destructive actions back to you instead of running them.

And if you customize your Claude Code status line, embo no longer
overwrites it on session start. It looks for an embo:auto-refresh line
in ~/.claude/statusline.sh; remove that line and your version stays
put, keep it and automatic updates keep coming.

/plugin marketplace update embo then /reload-plugins
